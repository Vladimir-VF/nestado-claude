# Нестадо

Маленький браузерний світ керамічних корів Неллі. Обираєш корову на холодильнику, гуляєш лугом-планетою, перемикаєшся між Вільною, Сонею і Приймою та допомагаєш їм.

Грати: https://vladimir-vf.github.io/nestado-claude/

## Керування

Телефон: ліва половина екрана працює як джойстик, торкання трави веде корову туди, свайп крутить камеру.
Компʼютер: стрілки або WASD, клік по траві, тягни мишкою, щоб крутити камеру.

## Авторство

Корови Вільна, Соня і Прийма: авторські керамічні фігурки Неллі, 3D-моделі за ними.
Природа: Stylized Nature MegaKit від Quaternius, ліцензія CC0.
Рушій: three.js r147, джойстик nipplejs.

## Як оновлюється

Кожен пуш у main запускає GitHub Actions: build.sh завантажує моделі, стискає їх і публікує сайт на GitHub Pages.
